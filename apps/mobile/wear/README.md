# The DoDone Wear OS app

A separate Android application module, in Kotlin and Compose for Wear OS.
React Native does not run on Wear OS, so none of `apps/mobile`'s screens can be
reused here — only the *decisions*, and those arrive precomputed in the snapshot
the phone sends (see `apps/mobile/lib/wear-snapshot.ts`).

It lives here rather than under `android/` because `android/` is gitignored and
regenerated by `expo prebuild`. `plugins/withWearApp.js` copies this tree into
`android/wear` on every prebuild and adds it to `settings.gradle`.

CI does not build this directory: it has no Android SDK. It has been built by
hand, debug and release, from a clean `expo prebuild`, and its JVM tests run
with `./gradlew :wear:testDebugUnitTest` from the generated `android/` project.
It has never run on an emulator or a watch. See `docs/wear-os-verification.md`
for what has to be checked on a device, in what order.
